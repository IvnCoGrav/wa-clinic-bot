### Deviasi kecil dari plan (disetujui/beralasan)

- **G1:** `/cta` tetap terbuka semua origin. `AdClick.landingUrl` masih menyimpan nilai klien untuk analitik, tetapi `event_source_url` CAPI dibatasi ke domain tenant (`trustLandingUrlForCapi`).
- **T1.3:** validasi host tidak ditambah sebagai allow-list baru karena resolusi tenant sudah lewat DB (`landing_domain`); vektor XSS ditutup di titik escaping (`applyPublicMetadata`).
- **`sanitizePhoneForRender`** menerima 6–15 digit agar nomor legacy/fixture tetap tampil; kontrak tulis admin tetap 8–15 digit.
- **`metaPixelId`** menerima `[A-Za-z0-9_]` 5–32 (bukan hanya digit) agar data lama seperti `PIXEL_123` tidak hilang; karakter kutip/`<`/`;` tetap ditolak.
